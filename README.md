# Сайт AMD-05 — инструкция по запуску (для не-программиста)

Что получится: сайт по вашей ссылке, который видят все. Вы заходите в админ-панель по паролю,
меняете товары и фото, нажимаете «Опубликовать» — и все посетители видят изменения.

Нужны: бесплатные аккаунты на GitHub и Netlify. Время: 20–30 минут.

## Шаг 1. Регистрация на GitHub
1. Откройте https://github.com и нажмите Sign up. Введите почту, придумайте пароль и имя, подтвердите почту.

## Шаг 2. Создайте репозиторий (папку для сайта)
1. На GitHub нажмите «+» справа сверху → New repository.
2. Название: `amd05-site`. Поставьте галочку **Private** (чтобы код был закрыт). Нажмите Create repository.
3. На открывшейся странице нажмите ссылку **uploading an existing file**.

## Шаг 3. Загрузите файлы сайта
1. Распакуйте архив `amd05-netlify.zip` на компьютере.
2. Откройте распакованную папку `amd05-site` и выделите **всё её содержимое**
   (папки `netlify`, `public` и файлы `netlify.toml`, `package.json`, `README.md`).
   Важно: загружать нужно содержимое, а не саму папку.
3. Перетащите всё в окно GitHub. Дождитесь загрузки (полоски исчезнут).
4. Внизу нажмите зелёную кнопку **Commit changes**.
5. Проверьте: в репозитории должны быть видны папки `netlify` и `public` и файл `netlify.toml`.

## Шаг 4. Netlify
1. Откройте https://app.netlify.com → Sign up → выберите **Sign up with GitHub** и разрешите доступ.
2. Нажмите **Add new project → Import an existing project → GitHub**, выберите `amd05-site`.
3. Настройки менять не нужно (всё уже в файле `netlify.toml`). Нажмите **Deploy**.
4. Подождите 1–2 минуты. Netlify даст адрес вида `что-то.netlify.app`.

## Шаг 5. Задайте пароль админа (обязательно!)
1. В Netlify откройте ваш сайт → **Project configuration → Environment variables**.
2. Нажмите **Add a variable**:
   - Key (имя): `ADMIN_PASSWORD`
   - Value (значение): ваш пароль (длинный, например 12+ символов, придумайте сами).
3. Сохраните. Затем откройте **Deploys → Trigger deploy → Deploy project without cache**.
   Без этого перезапуска пароль не заработает.
4. Пароль никому не показывайте. Он хранится только в Netlify, а не в коде сайта.

## Шаг 6. Проверка
1. Откройте ваш адрес `…netlify.app` — на сайте должны быть 4 монитора.
2. Нажмите «Вход для администратора» (внизу сайта), введите пароль. Неверный пароль должен выдать ошибку.
3. Добавьте тестовый товар с фото → **Опубликовать**.
4. Откройте сайт с телефона (или в режиме инкогнито) — товар должен появиться.
   После этого тестовый товар можно удалить и снова опубликовать.

## Шаг 7. Свой домен (по желанию)
1. Купите домен у любого регистратора (например reg.ru).
2. В Netlify: **Domain management → Add a domain** → введите домен.
3. Netlify покажет, какие записи (DNS) нужно прописать у регистратора. Повторите их там.
   Через несколько минут–часов сайт заработает по вашему домену, HTTPS включится сам.

## Как пользоваться каждый день
Заходите на сайт → «Вход для администратора» → пароль → меняете товары/цены/фото/описания → **Опубликовать**.
Кнопка «Отменить правки» возвращает то, что сейчас опубликовано.
Предыдущая версия каталога перед каждой публикацией сохраняется автоматически.

## Если что-то не работает
- «Админка не настроена»: не задан `ADMIN_PASSWORD` или после этого не сделан Trigger deploy (шаг 5).
- Пароль «неверный»: проверьте раскладку и лишние пробелы; при необходимости задайте заново и сделайте новый deploy.
- Товары не обновляются: нажмите Ctrl+F5 на сайте.
- В Netlify откройте **Logs → Functions** — там видны ошибки.

## Что внутри
- `public/` — сайт и картинки.
- `netlify/functions/` — серверная часть: каталог, фото и админ (хранение в Netlify Blobs).
- `netlify.toml`, `package.json` — настройки.

## Обновление: юридические страницы
Вместе с этим архивом идёт файл `ПАМЯТКА_ВЛАДЕЛЬЦУ.md`: прочитайте его перед публикацией.
В нём: что вписать в `public/legal-config.js`, как залить обновление на GitHub, про уведомление Роскомнадзора и вопросы юристу.
